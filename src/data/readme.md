## 📊 Data Pipeline

### Input: Raw Data
**File**: `yandex_realty_manual.csv`
- Source: Web scraper (`src/parsing/ya_parser_raw.ipynb`)
- Records: Unvalidated apartment listings
- Features: 19+ raw attributes

### Processing: `pandera.ipynb`
The validation notebook performs:

1. **Schema Validation**
   - Defines expected data types for each column
   - Enforces constraints (min/max values, ranges)
   - Validates categorical value domains

2. **Data Cleaning**
   - Removes duplicates
   - Handles missing values
   - Normalizes numeric fields (prices, areas, floors)
   - Standardizes categorical values

3. **Quality Checks**
   - Outlier detection
   - Data consistency validation
   - Missing value analysis
   - Invalid records reporting

4. **Output**
   - `yandex_realty_cleaned.parquet` - Clean, validated dataset
   - `invalid_records.csv` - Records failing validation

### Output: Clean Data
**File**: `yandex_realty_cleaned.parquet`
- Format: Apache Parquet (compressed, columnar)
- Records: ~60K validated listings
- Ready for modeling pipeline

### Enhanced Data
**File**: `ya_realty_with_txt_embeds.parquet`
- Extends cleaned data with text embeddings
- Generated by: `src/modeling/text/encoding.ipynb`
- Contains encoded description features

## 🗄️ S3 Storage Client

### File: `s3_client.py`

MinIO S3-compatible storage wrapper for managing project data across buckets.

#### Key Features

**Bucket Management**
```python
from src.data.s3_client import MinIOS3Client

client = MinIOS3Client()
client.create_bucket('tabular-data')
client.list_buckets()
```

**Upload Operations**
```python
# Upload DataFrame
client.upload_dataframe(
    df=my_dataframe,
    bucket='tabular-data',
    object_name='yandex_realty_cleaned.parquet'
)

# Upload file
client.upload_file(
    file_path='/path/to/file.csv',
    bucket='tabular-data',
    object_name='data.csv'
)
```

**Download Operations**
```python
# Download DataFrame
df = client.download_dataframe(
    bucket='tabular-data',
    object_name='yandex_realty_cleaned.parquet'
)

# Download file
client.download_file(
    bucket='tabular-data',
    object_name='data.csv',
    file_path='/local/path/data.csv'
)
```

**Object Management**
```python
# List objects
objects = client.list_objects('tabular-data')

# Delete object
client.delete_object('tabular-data', 'old_file.csv')

# Check existence
exists = client.object_exists('tabular-data', 'file.csv')
```

#### Configuration

```python
client = MinIOS3Client(
    endpoint_url='http://localhost:9000',      # MinIO endpoint
    access_key='minioadmin',                   # Access credentials
    secret_key='minioadmin123',
    secure=False                               # HTTP (not HTTPS)
)
```

## ✅ Data Validation

### Pandera Schema

The validation notebook defines schemas for:

| Feature | Type | Constraints |
|---------|------|-------------|
| `price_numeric` | Int64 | > 0, < 100,000,000 |
| `area` | Float64 | > 5, < 500 |
| `metro_time` | Int64 | 0-120 minutes |
| `rooms` | Category | 0, 1, 2, 3+ |
| `author` | Category | agency, owner, realtor |
| `self_floor` | Int64 | >= 1 |
| `max_floor` | Int64 | > self_floor |
| `description` | String | Non-empty |

### Validation Rules

✅ **Type Checking**: Ensures correct data types  
✅ **Null Handling**: Detects missing values  
✅ **Range Validation**: Enforces min/max bounds  
✅ **Categorical Constraints**: Validates allowed values  
✅ **Referential Integrity**: Checks relationships (e.g., floor < max_floor)  
✅ **Duplicate Detection**: Identifies duplicate listings

## 💻 Usage Examples

### Complete Data Pipeline

```python
# 1. Load raw data
import pandas as pd
df_raw = pd.read_csv('tabular/yandex_realty_manual.csv')

# 2. Validate & clean (run pandera.ipynb)
# This generates yandex_realty_cleaned.parquet

# 3. Upload to S3 storage
from src.data.s3_client import MinIOS3Client

client = MinIOS3Client()
client.upload_dataframe(
    df=pd.read_parquet('tabular/yandex_realty_cleaned.parquet'),
    bucket='tabular-data',
    object_name='yandex_realty_cleaned.parquet'
)

# 4. Download for modeling
df_clean = client.download_dataframe(
    bucket='tabular-data',
    object_name='yandex_realty_cleaned.parquet'
)
```

### Working with S3 Client

```python
from src.data.s3_client import MinIOS3Client
import pandas as pd

# Initialize client
client = MinIOS3Client()

# Create buckets
client.create_bucket('embeddings')
client.create_bucket('photos')

# Upload multiple files
for file in ['embeddings.parquet', 'metadata.json']:
    client.upload_file(file, 'embeddings', file)

# List all objects
all_objects = client.list_objects('embeddings')
print(f"Found {len(all_objects)} objects")

# Download specific dataset
embeddings = client.download_dataframe(
    'embeddings',
    'embeddings.parquet'
)
```

## ⚙️ Configuration

### MinIO Docker Setup

```bash
# Start MinIO container (see docker-compose.yml)
docker-compose up -d

# Access web UI
# URL: http://localhost:9001
# Login: minioadmin / minioadmin123
```

### Environment Variables (Optional)

```bash
export MINIO_ENDPOINT="http://localhost:9000"
export MINIO_ACCESS_KEY="minioadmin"
export MINIO_SECRET_KEY="minioadmin123"
```

### Data Version Control (DVC)

```bash
# Track data file
dvc add tabular/yandex_realty_cleaned.parquet

# Push to remote storage
dvc push

# Pull specific version
dvc pull tabular/yandex_realty_cleaned.parquet.dvc
```

## 📝 Notes

- **Compression**: Parquet format reduces file size by ~80% vs CSV
- **Auto-creation**: S3 client creates directories automatically
- **Incremental Updates**: Can append new records maintaining validation
- **Performance**: Parquet enables fast filtering in downstream jobs
- **Lineage**: `.dvc` files maintain data provenance
